# Changelog

## 1.1.0 (2)

- Replaced the startup dashboard with Today, Tasks and Focus. Calendar, advanced task views, habits and settings are available under More options.
- Removed automatic starter data and both workspace replacement actions. Existing workspace rows are retained.
- Added title-only task creation and a focused timer. The basic editor leaves scheduling, projects, and reminders optional.
- Rebuilt the existing launcher widget around pending tasks, task creation, completion and focus. Repeated completion actions no longer create duplicate recurrences.
